# 群聊热力图可视化 - 开发文档

## 1. 项目概述

### 1.1 项目目标
将 Telegram 群聊导出的 JSON 数据转化为直观的可视化热力图，帮助用户分析群聊的活跃时段和话题分布。

### 1.2 技术架构

```
┌─────────────┐     ┌──────────────────┐     ┌─────────────┐
│ result.json │────▶│ data_processor.py │────▶│ 前端可视化  │
│ (原始数据)  │     │  (Python处理)     │     │ (ECharts)   │
└─────────────┘     └──────────────────┘     └─────────────┘
                           │
                    ┌──────┴──────┐
                    │processed_data│
                    │  .json      │
                    └─────────────┘
```

### 1.3 技术选型

| 层次 | 技术 | 选型理由 |
|------|------|----------|
| 数据处理 | Python 3.x | 丰富的JSON处理能力，易于扩展 |
| 前端可视化 | ECharts 5.x | 功能强大的图表库，热力图支持好 |
| 样式 | CSS3 | 现代化的视觉效果 |
| 服务 | Python http.server | 零依赖的本地静态服务 |

## 2. 模块详细设计

### 2.1 数据处理模块 (data_processor.py)

#### 2.1.1 核心函数

**load_data(json_path)**
- 功能：加载 JSON 数据文件
- 输入：JSON 文件路径
- 输出：解析后的字典对象

**extract_text(msg)**
- 功能：从消息对象中提取纯文本
- 处理逻辑：
  1. 检查消息类型（仅处理 `message` 类型）
  2. 兼容 `text` 字段为字符串或数组两种格式
  3. 数组格式时，提取所有 `text` 实体并拼接
- 返回：纯文本字符串

**parse_datetime(date_str)**
- 功能：解析 ISO8601 格式的日期字符串
- 使用 `datetime.fromisoformat()` 进行解析

**simple_tokenize(text)**
- 功能：简单分词处理
- 处理逻辑：
  1. 清洗文本（去除特殊字符）
  2. 提取中文字符段
  3. 中文：生成双字组合 + 整词
  4. 英文/数字：按空格分词
- 返回：分词列表

**filter_tokens(tokens)**
- 功能：过滤停用词
- 使用内置停用词表 `STOP_WORDS` 进行过滤

**build_activity_heatmap(messages)**
- 功能：构建活跃度热力图数据
- 数据结构：`{ "星期_小时": 消息数 }`
- 遍历所有消息，按星期×小时聚合

**build_topic_heatmap(messages)**
- 功能：构建话题热力图数据
- 数据结构：`{ "星期_小时": [[关键词, 频次], ...] }`
- 每个时段提取 Top5 关键词

**build_daily_summary(messages)**
- 功能：构建每日汇总
- 统计每日：消息数、活跃用户、首末消息时间、高峰时段

**build_top_users(messages, top_n=20)**
- 功能：统计活跃用户排行
- 返回前 N 名用户及其消息数

**build_time_period_stats(messages)**
- 功能：按时段统计特征
- 时段划分：凌晨(0-6)、上午(6-12)、下午(12-18)、晚上(18-24)
- 统计各时段消息量和 Top15 关键词

#### 2.1.2 数据流向

```
原始消息列表
    │
    ├──▶ 活跃度统计 ──▶ activity_heatmap
    │
    ├──▶ 话题提取 ──▶ topic_heatmap
    │
    ├──▶ 每日汇总 ──▶ daily_summary
    │
    ├──▶ 用户统计 ──▶ top_users
    │
    └──▶ 时段分析 ──▶ time_period_stats
                │
                └──▶ 汇总为 processed_data.json
```

### 2.2 可视化模块 (index.html)

#### 2.2.1 图表组件

**活跃度热力图 (activityChart)**
- 类型：ECharts heatmap
- X 轴：24 小时
- Y 轴：周一至周日
- 颜色：紫粉渐变色阶
- 交互：悬停显示消息数和热门话题

**每日趋势图 (dailyChart)**
- 类型：ECharts bar
- X 轴：日期
- Y 轴：消息数
- 交互：悬停显示详细统计

**小时分布图 (hourChart)**
- 类型：ECharts line + area
- X 轴：0:00 - 23:00
- Y 轴：消息总数
- 标记：最高点高亮

**话题卡片 (topicSection)**
- 四个时段卡片
- 展示各时段 Top15 关键词
- 标签云样式展示

**用户排行榜 (userList)**
- Grid 布局展示
- 前3名特殊配色
- 悬停交互效果

#### 2.2.2 视觉设计

**配色方案（暗色主题）**
- 背景：深蓝渐变 `#0a0a1a → #16213e`
- 主色：紫色渐变 `#667eea → #764ba2`
- 强调：粉色 `#f093fb`
- 文字：浅灰 `#e0e0e0`

**响应式布局**
- 使用 CSS Grid 和 Flexbox
- 支持移动端适配
- 断点：768px

## 4. 扩展指南

### 4.1 添加新的统计维度

1. 在 `data_processor.py` 中添加新的统计函数
2. 在 `main()` 函数中调用并添加到 result 字典
3. 在 `index.html` 中添加对应的图表组件

示例 - 添加按用户×时段统计：
```python
def build_user_time_heatmap(messages):
    user_time = defaultdict(lambda: defaultdict(int))
    for msg in messages:
        dt = parse_datetime(msg.get('date', ''))
        if dt:
            user = msg.get('from') or msg.get('actor') or '未知'
            hour = dt.hour
            user_time[user][hour] += 1
    return dict(user_time)
```

### 4.2 集成真实分词库

替换 `simple_tokenize()` 为 jieba 分词：
```python
import jieba

def jieba_tokenize(text):
    return [t for t in jieba.cut(text) if t.strip()]
```

### 4.3 导出为图片

可通过 ECharts 的 `getDataURL()` 方法导出图表：
```javascript
const url = activityChartInstance.getDataURL({ type: 'png', pixelRatio: 2 });
```

## 5. 性能优化

### 5.1 当前性能
- 数据量：2.2万条消息
- 处理时间：< 5秒
- 前端渲染：< 1秒

### 5.2 大数据量优化建议
- 使用流式处理大 JSON 文件
- 按需加载数据分片
- 使用 Web Worker 进行分词计算
- 前端使用虚拟滚动展示大量数据
